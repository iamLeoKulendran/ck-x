1. `q6_s1` / `q8_s2`: jq `// true` fallback treats an explicit `false` as falsy,
   so `allowPrivilegeEscalation: false` was rejected. Fixed to compare the raw
   `jq -r '.allowPrivilegeEscalation'` output.
2. `q16_s3`: pod selection could pick the old terminating (still writable) pod
   during rollout. Fixed to select the newest Running pod by creationTimestamp.
3. Setup reset gap: `kubectl apply` does not strip candidate fields added via
   `kubectl patch` (not in last-applied-configuration), so re-running setup did
   not always restore the broken state. Fixed q4/q6/q7/q8/q10/q11/q16 setups to
   delete-then-apply the broken deployment.

All three fixes were re-verified: fresh state fails, solved state passes.
